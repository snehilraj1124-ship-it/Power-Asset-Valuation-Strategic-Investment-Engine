# Voltaris — Power Asset Valuation & Strategic Investment Engine

## 📌 Overview

**Voltaris** is a full-stack **Power Asset Valuation & Strategic Investment Engine** that combines electrical engineering, energy economics, corporate finance, and strategic investment analysis.

The platform is designed to evaluate electricity-generation assets such as **solar, wind, and hybrid power assets** by analyzing their operational characteristics, financial performance, replacement economics, and long-term investment value.

Voltaris uses **Discounted Cash Flow (DCF)** based valuation to estimate enterprise value and equity value under different strategic scenarios.

---

## 🎯 Objectives

Voltaris is designed to help users:

- Analyze power-generation assets
- Track asset capacity and availability
- Evaluate asset financial performance
- Compare book value and replacement cost
- Analyze revenue and operating expenses
- Estimate future cash flows
- Calculate enterprise value
- Calculate equity value
- Calculate value per MW
- Compare different valuation scenarios
- Support strategic investment decisions
- Evaluate energy infrastructure portfolios

---

## 🚀 Key Features

### 1. Power Asset Management

Users can create and manage power-generation assets with:

- Asset name
- Technology type
- Installed capacity
- Asset age
- Book value
- Replacement cost
- Annual revenue
- Annual operating expenditure
- Availability percentage

Supported technologies include:

- Solar
- Wind
- Solar + Storage
- Hybrid generation assets
